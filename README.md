# NPI — Tótem Punto de Información ETSIIT (Leap Motion)

Punto de información interactivo para la **ETSIIT (Universidad de Granada)** controlado mediante gestos aéreos con **Leap Motion**, desarrollado para la Práctica 2 de **Nuevos Paradigmas de Interacción (NPI)**.

## Stack Tecnológico
- **Frontend:** HTML5 / CSS3 / JavaScript (formato vertical `9:16` para TV del laboratorio).
- **Visor 3D:** Three.js.
- **Interacción Gestual:** Leap Motion SDK / WebSocket (`leapjs`).
- **Continuidad con App Móvil (Práctica 1):** Códigos QR dinámicos.
